### 接线现状

```
Legacy agent (agent/core.py):
  Pipeline A (pre-provider): Tool Budget → Snip+Micro(合) → Budget Degradation → Collapse
  Pipeline B (context assembly): TokenPlanner → MicroCompactor(v2) → DeterministicTrimmer

Native aiterate:
  ContextBudgetManager.ensure_budget()  ← 单层 token 裁剪，不知以上组件存在
```

### 关键发现

1. **Snip 和 Collapse 都可以包装为 `CompactionStrategy`**（v2 接口）——改动量小
2. **v1 的 MicroCompactor 有工具名过滤**（`COMPACTABLE_TOOLS` frozenset），v2 没有——纯尺寸过滤
3. **Collapse 需要 stateful wrapper**：内部持有 `CollapseStore`，需要注入 `summarizer`
4. **`ContextWindowManager.build_context()` 消费 `list[dict]`**——`NativeConversation.to_api_format()` 已能做转换
5. **接线路径清晰**：在 `aiterate` 中替换 `ContextBudgetManager.ensure_budget()` → `ContextWindowManager.build_context()`

### 3f. Completion Guard 详情

`agent/completion_guard.py` 实现了一套 Zero Trust 完成验证系统：
- **NOT 计数器驱动**：进度由 FACTS（磁盘上的文件变更、git diff 证据）衡量，不是"工具调用了多少次"

- **`evaluate_completion()` 管道**：stop hook → 多个独立 check → guard → facts → block tracker → 三态决策 (COMPLETE / RETRY / GIVE_UP)
