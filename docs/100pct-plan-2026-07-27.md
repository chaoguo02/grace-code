## 批次 1：Memory 衰退与实体链（75% → 100%）

### M1.1 decay_confidences() 定期调度
- **文件**：`server/services/agent_service.py`
- **现状**：`prune_expired()` 仅在启动/关闭调用一次。`decay_confidences()` 从未被定期触发
- **修改**：在 `__init__` 末尾启动一个 daemon 后台线程，每 6 小时调用 `self._memory_store.prune_expired()`
- **预期**：低置信度（<0.2）自动 deprecated，90天未访问记忆 confidence×0.9
- **验证**：写入一条 confidence=0.3 的记忆，手动将 updated_at 改为 91 天前，等维护线程触发后确认 status='deprecated'

### M1.2 anchor content_hash 校验
- **文件**：`memory/injection_service.py`
- **现状**：`content_hash` 字段存在但在注入时从未与当前文件 hash 对比
- **修改**：`_build_always_inject_section()` 注入前对每个 anchor 做 `hashlib.sha256(file.read_bytes()).hexdigest()` 比较，不匹配则标记 `status='deprecated'`
- **预期**：文件被编辑后绑定的 feedback 记忆自动废弃
- **验证**：创建锚定 `agent/core.py:42` 的 feedback 记忆 → 编辑 `agent/core.py:42` → 下次注入时该记忆被 deprecated

### M1.3 Memory 实体链 Web 可视化
- **文件**：`web/src/components/MemoryView.tsx`
- **现状**：detail 面板显示 anchors 但无跨记忆关系图
- **修改**：
  - 后端：`GET /api/memory/{name}/edges` 返回关联记忆
  - 前端：detail 面板底部新增 "Linked Memories" 区域，显示 source→target→relation_type 关系链
- **预期**：选中一条记忆时看到它关联的其他记忆及关系类型
- **验证**：创建两条关联记忆 → 在 Memory Tab 选中其一 → 看到关联列表

### M1.4 Revision 历史 UI
- **文件**：`web/src/components/MemoryView.tsx`

## 批次 2：长上下文切分（60% → 100%）

### C1.1 压缩后 DB message 清理
- **文件**：`server/services/agent_service.py` `compact_session_async()`
- **现状**：`ConversationCompactor.compact_history()` 返回压缩后的消息列表，但 `_compact()` 只追加 recovery message，旧消息仍在 DB
- **修改**：压缩完成后调用 `_storage.replace_messages(session_id, compacted_messages)` 替换旧消息
- **预期**：`total_tokens_estimate` 压缩后立即下降，context 用量条实时反映
- **验证**：压缩前记录 message count → `/compact` → 压缩后 message count 减少

### C1.2 压缩后索引防膨胀
- **文件**：`memory/consolidation.py`
- **现状**：`_dream_prune()` 只裁剪 `MEMORY.md` 文件，不管 SQLite 索引
- **修改**：`run_consolidation()` 增加 `index_vacuum()` 调用（SQLite `PRAGMA optimize`）
- **预期**：多次压缩后 DB 文件不异常膨胀
- **验证**：连续 10 次压缩后 DB size 增长 <10%

### C1.3 上下文预算仪表盘
- **文件**：`web/src/components/ContextInspector.tsx`（增强）
- **现状**：ContextInspector 显示 snapshots 但无预算规划视图
- **修改**：
  - 增加预算仪表盘：当前用量/总预算/压缩建议
  - 当用量 >80% 时显示 "建议压缩" 黄色警告
  - 当用量 >95% 时显示 "必须压缩" 红色警告
  - 显示最近一次压缩时间和效果（压缩前→后 tokens）
- **预期**：用户可看到何时需要压缩及历史压缩效果
- **验证**：长 session 上下文超 80% → ContextInspector 显示警告
